# 按任务选择完整模板

先看使用目的，再看表达偏好；用户指定现有样式时直接沿用。给资料但用途不清晰时，默认极简，不把选样式变成必答问题。以下是选择依据，不是使用量排名，也不必整表发给用户。

| 用户要完成的事情 | 推荐完整样式 | 选择理由 |
|---|---|---|
| 文章速读、一般资料，或用途未说明 | MMK0V1 极简 | 主次清楚，低干扰 |
| 读书笔记、章节消化 | MMR0C2 自然 | 适合把章节连成理解 |
| 长文精读、文献论证 | MMV0EA 知识提纲 | 紧凑分节，逐层回看 |
| 知识复习、概念回忆 | MMS0BF 语义索引 | 便于按线索查找与复习 |
| 代码模块、技术文档 | MMT0H3 石板经典 | 区分模块与职责 |
| 业务分析、复盘汇报 | MMC0Y9 商务蓝图 | 结论、原因和行动清楚落位 |
| 团队架构、职责归属 | MMF0KB 组织分层 | 自上而下区分责任层级 |
| 项目范围、交付与任务拆解 | MMA0RE 项目分解 | 把目标拆成可做的工作项 |
| 分享演示、讲述提纲 | MMB0Q4 彩虹经典 | 论点分组鲜明，便于跟随 |
| 内容选题、创作方向 | MMW0F5 暗夜粉彩 | 区分不同的创作角度 |
| 写作草稿、论点构思 | MMD0N6 随手画画 | 容纳尚未定稿的思路 |
| 概念讲解、定义与例子 | MMN0WD 概念分组 | 清楚区分定义、边界与应用 |
| 自由脑洞、趣味联想 | MMP0A7 脑洞涂鸦 | 轻松发散，边画边想 |
| 工作与生活随想 | MMH0S8 浮生小趣 | 蓝灰纸笺与小毛驴，把现实想得轻巧一点 |
| 收集点子、共同构思 | MMQ0DC 便签共创 | 点子平等呈现，方便归类 |
| 讨论观点、方案与顾虑归类 | MME0TG 彩色研讨 | 按主题整理不同意见 |

用户只说“手绘”时选随手画画，“好玩”选脑洞涂鸦，“商务”选商务蓝图。多项用途并存时以最终交付目的为准，例如“读完资料做汇报”优先商务蓝图；用户明确强调的限制优先。只用一句话说明所选名称与理由，不夸称对所有人最优。

名称、简称和固定配方以`node "<skill-dir>/scripts/render.cjs" --list`为准。保持16套默认配方不变；不要为了单次请求重写内置组件或悄悄修改预设。
