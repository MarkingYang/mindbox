# 浮生小趣 · 十六枚生活笔触

MMH0S8 / P68 从粉笔夜谈改为浮生小趣。固定 UID 与配方 `L01-N16-E09-C45-B42-T13-D03` 保留，旧名称继续作为导入别名。

## 视觉与内容

蓝灰画布 `#CCD9DE`、暖灰毛驴 `#B8B1A6`、浅鼻口 `#E8E2D7`、炭黑轮廓 `#292D32`、杏色点缀 `#D99670`。与脑洞涂鸦的米白纸面、豆芽搭子和复笔记号区分。角色、纸笺与记号均为原创内联 SVG，无图片外链、字体图标或栅格依赖。

角色八枚：借风不丢线、能干就多干、我稳得很、还有下一关、留一小园、等个懂的人、纸上大饼、帮忙不背锅。07 使用纸上画饼，不再使用交椅、量尺或小凳子的隐喻。

功能八枚：起念方笺、转念气泡、折页备忘、进度票签、轻划重点、绕圈想想、转个方向、暂存问号。前四种保留正文留白，后四种用于轻量提示。目录展示顺序与实际渲染的稳定身份表分离。

## 共享实现

`src/fusheng.cjs` 提供 `parts`、`families`、`colors(theme)`、`renderPart(id, options)` 与 `renderNode(node, theme)`。`library.themeFor` 在 N16/C45/B42 组合上声明 `family: fusheng`，所以更换结构和疏密仍保留该套笔触。N16 本身不改名或强行变成毛驴，其他手绘样式不受角色替换影响。

根节点和主分支使用纸笺，主分支按固定分支身份轮换四种容器和八种姿态；末端与深层逐渐简化为色标。D03 给顶部小角色预留 62 单位行距，根角色不高于 54 单位；D02/D01 只保留根角色并缩小。所有装饰均 `aria-hidden`、不接受指针事件，不更改正文、层级、顺序或节点状态。插画不自动判断用户的情绪、优先级或任务完成情况。

网站图鉴分为四种纸笺、四种记号、八个角色三个分组。仅该样式显示此图鉴；切换回脑洞涂鸦显示原32枚组件。网页、独立HTML、CLI和生成的Skill runtime通过同一文档组装器使用该模块。

## 验证

`tests/fusheng.test.cjs` 覆盖身份/别名、16枚有效SVG、五种结构与三档疏密、深层多行正文、稳定装饰身份、实际范例全部16枚参与渲染，以及站点与Skill分发一致性。通用测试继续检查16套样式的正文、深层布局、离线导出与安装。

纸笺与提示按4＋4分组，移除与方笺接近的叠页归档，新增暂存问号。问号提供独立可复用图形，只呼应作者以中英文问号结尾的二级及更深节点，不随机替正文增加疑问。八个角色姿态不变。

`examples/small-joys.md` 以AI助力、职场负担、面试镇定、求职闯关、生活期待和责任边界组织八个分支，完整展示8＋4＋4组件。“第几轮才算最后一轮？”与“下一站想遇见什么？”明确承载暂存问号。图鉴的范例入口直接打开这一共享范例，不再跳回内容无关的通用预览。卡片封面仅预览部分分支，完整图仍可编辑。
