# 脑洞涂鸦 · 32枚组件

P67 / MMP0A7继续使用原配方和无横线速写本。32枚是样式内部的SVG笔触，用户仍然只选“脑洞涂鸦”，无需逐枚选择。原16枚ID保持不变，追加16枚；按9种纸片、9种记号、14种小搭子分为三个角色目录。纸片按完整主题到片段排序，记号由底纹到点缀，小搭子沿好奇、琢磨、动手、放松的节奏排列。目录顺序与生成用的稳定造型表分开维护。

## 视觉约束

豆芽头、墨色轮廓、小色块衣服构成共同身份。姿势和小道具表达不同动作，不加入文字、勾选状态或额外的逻辑关系。C提供强调色，B提供纸面，T保持独立；所有组件仍为可放大的矢量。轮廓沿节点的排版边界绘制，折角、撕边和装订只占用页边。

## 组合规则

- 根主题保留纸片、探头搭子、胶带与小星光，作为这套样式的识别点。
- 一级分支按分支选择九种容器，按稳定节点ID选择小搭子。舒展布局才出现分支搭子。
- 二级中间主题少量使用纸笺，末端文字统一使用色标或双笔下划；多行文字的笔迹位于最后一行下沿。只给有留白的节点一个次要装饰位；搭子与小记号互斥，纸笺不再叠角落小记号；小记号降低到约三分之一的候选节点，避免一整排装饰争抢注意力。
- 三级及以下沿用渐轻的层级笔迹，不堆容器和小人。D02去掉分支小人，D01只留标题搭子。
- 同一节点折叠前后造型稳定。没有渲染时随机数，也不依据语义猜测“完成”“重要”等标记。

## 维护与验证

`src/doodle.cjs`为组件和组合的唯一实现。网站组件册、预览、Skill与独立HTML复用它。组件册展示32枚完整图形；真实导图依据内容分配，不要求一张小图塞满32枚。

测试覆盖32枚ID/独立SVG/稳定输出、14种姿态、三类目录的完整覆盖与排序隔离、235节点真实布局中的全部组件、五种结构映射、紧凑密度、折叠稳定性与配色对比度。结构测试不代表所有浏览器和所有内容的视觉效果；实际浏览器证据单独记录在verification.md。
