Choose your assistant when prompted. This follows the default branch. For the pinned stable release and extra host adapters, see [installation](installation.md).

## Listing copy / 对外介绍

### 中文

Mindbox 是一个把笔记、文档和零散想法整理成可编辑思维导图的 Agent Skill。16 套完整样式，输出可离线打开的独立 HTML。支持展开分支、双击改字、调整层级和保存后继续交给 AI 修改。资料理解由现有 AI 助手提供。

### English

Mindbox turns notes, documents and unfinished ideas into editable mind maps through your existing AI assistant. Choose from 16 complete styles and receive a standalone HTML file with embedded fonts and code. Fold branches, edit text and hierarchy, save the file, and give the latest HTML back to your assistant for further revision.

Categories: Knowledge management; Productivity; Mind mapping; Agent Skills.
