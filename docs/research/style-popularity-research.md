# 16 套样式的使用信号与补充依据

核查日期：2026-10-20。保留原8套，新增P73–P80；七个组件维度仍各不超过8项，字体维持4中文+4英文。

## 数据方法与限制

优先采用可明确辨认的用户行为信号。Miro 列表HTML把两类计数明确标为 `copies-stat` 与 `likes-stat`，本次以累计复制量优先，点赞仅补充。数据来自同一次分类页快照，保留站点显示的K近似值，没有将复制量改写成独立用户数。

复制整份模板同时受到内容、曝光、发布时间等影响，不等于对配色、节点或字体的单独偏好。没有时间窗口，不能计算近期使用频率或增长；也不能把不同平台的数据合成全网排行榜。因此本次是“按可验证使用信号支持、兼顾视觉差异的八个补充方向”，不声称全网最热门八款或用户最喜爱的16款。

## 跨平台核对

- [Miro 模板库](https://miro.com/templates/mind-maps/?page=1)：提供可核实的模板复制与点赞信号，作为本轮主要定量依据。
- [ProcessOn 克隆最多](https://www.processon.com/template/all/cc)：公开入口出现正式风格、学习提纲、组织架构等用途，作为补充方向；没有取得本次各样式的具体克隆数，不虚构排名。其[官方说明](https://www.processon.com/support/question/5229b2820cf204f505bc694f)解释克隆即把文件作为模板使用。
- [Xmind 模板市场](https://templates.xmind.com/?lang=en)：学习、项目启动与目标梳理被列为精选用途；精选推荐不等于使用排名。
- [MindMeister 产品说明](https://mindmeister.com/pages/product-tour)：支持导图、大纲与列表视图，辅助确定长内容阅读方向；平台用户规模未用作具体样式的偏好证据。

视觉迁移均为现有组件的原创组合，不是原模板精确复制。P77/P79仍保留树状层级，未实现通用概念网络的跨节点关系；P80不自动生成六顶思考帽的具体方法内容。相关主题的实际语义由输入内容决定。
