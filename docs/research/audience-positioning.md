# 十六套样式的任务定位与市场判断

核查与实现：2026-10-20，0.14.0。保持16套配方、七维组件与原有代号；本轮优化选择路径、任务范例和卡片信息层次。没有新增账户、协作、自动抓取或AI分析功能。

## 优先服务谁

首要人群是已经使用AI助手、持续把资料整理为判断或成果的个人知识工作者。核心循环是“输入资料—看清层次—修正理解—输出/分享”。人群与任务有交叉，不按职业限制配方。

1. 阅读研究型知识工作者：研究者、分析师、长期学习者。资料输入与反复回看需求较贴近原产品目标。
2. 产品、运营和项目负责人：经常需要把需求、业务现状或项目范围讲清楚，输出HTML便于展示。当前没有团队实时协作与项目执行追踪，不将它定位为项目管理工具。
3. 内容创作者、顾问与讲师：选题、写作、解释概念和备课，兼顾结构和视觉表达。
4. 开发者与技术写作者是与Codex/Workbuddy渠道契合的切入人群。代码模块导览是一种层级阅读，当前不是自动代码分析或架构依赖图。

这是结合工作流匹配、重复任务机会、输出价值和渠道适配的产品优先级假设。尚无本站留存、职业分布、付费或导出数据，不能据此证明哪类人使用最多或最愿付费。学生/考试学习是可覆盖场景，但现阶段没有移动学习、题库等能力，暂不作为唯一获客定位。

## 让用户先认出任务，再比较表达

四个入口各包含4套推荐；任务归类是引导，不限制样式能用于其他内容。

| 任务入口 | 样式与定位 |
|---|---|
| 阅读学习 | 极简/文章速读；自然/读书消化；知识提纲/长文精读；语义索引/知识复习 |
| 工作规划 | 石板经典/代码理解；商务蓝图/业务汇报；组织分层/职责梳理；项目分解/项目拆解 |
| 写作表达 | 彩虹经典/演示提纲；暗夜粉彩/选题孵化；随手画画/写作草稿；概念分组/概念讲解 |
| 灵感构思 | 脑洞涂鸦/自由脑洞；粉笔夜谈/课前构思；便签共创/点子收集；彩色研讨/观点归类 |

每张卡先展示任务导图，再展示样式名、用途、预期结果、表达特点、适用人群、真实L/D与字体、完整配方和应用操作。真实任务预览包含三组主分支、每组两个子节点。中英文各自有对应范例，跟随该预设的T语言展示。切换样式继续保留用户当前内容，不自动套用范例。

快捷起点收敛为每类两套，共8套；目录仍有16套。每个组件维度继续不超过8项。搜索支持任务、人群、风格、组件和配方代号。

## 后续如何判断定位是否有效

先做小规模可用性验证：用户在不听讲解时，能否在10秒内找到符合自己任务的一套，并说出选择理由。10秒是验证目标，不是已达成的数据。

再在取得实际测量能力后观察任务入口点击、首次应用、导出和回访；复制只统计成功操作，区分本机事件与跨用户汇总。当前未实现分析采集，不展示虚构使用量或“热门第一”。
