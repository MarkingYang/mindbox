# mindbox 的层级自适应

同一份规则供网站、Skill、SVG、PNG与WebP使用；模型只负责文字和层级，不为新深度编写样式。

## 规则

保留根节点、一级主题、二级要点的既有表现。三级进入细节角色，四级及以后进入批注角色；每增加一级，连续递推填色、边界、字号、行高、留白和线宽，而不是复制上一级或循环换皮。

| 风格语言 | 第三级细节 | 第四级及以后 |
|---|---|---|
| 极简/商务/概念/项目细框 | 更轻的细框与小圆角 | 留边角的开放式批注；纵向结构用顶部标记 |
| 彩虹/组织/研讨实色卡片 | 白底或淡底描边，保留分支色侧标 | 无框文字、短划线与小圆点 |
| 暗夜粉彩贴片 | 较轻的粉彩底和短缝边 | 淡色笔记与断续短线 |
| 速写/粉笔/便签 | 单笔手绘框，去掉厚重复笔和排线 | 随手划线与点注 |
| 脑洞涂鸦 | 小段色标与手绘笔记记号 | 更轻的色标与墨点，不不断叠加人物 |
| 自然/石板/语义彩枝 | 细枝、点注 | 短页标与更轻的枝线 |
| 无框文字提纲 | 行内小圆点 | 细页标与缩进层次 |

三级起令 r = 1 / (1 + 0.45 × (depth − 2))。逻辑字号为12+2r，行高17+4r，水平内边距22+20r；笔触宽度、标记透明度同样连续有界。不会无限缩小，也不会第六级开始完全重复第五级。大图全图缩放可能让屏幕字变小，仍可放大或用阅读演示逐段查看。

层级仍保留20层子节点（含根共21层）的技术保护。0.40起移除固定节点配额，按内容复杂度展开；500与1000节点作为额外验证样本，不是新的容量承诺。分支色、字体和画布材质继承原模板；文字与其底色保持至少4.5:1对比度。布局测量与文字绘制使用相同字号和行高，避免只改画面造成节点重叠。折叠不改变剩余节点的样式。

## 范例与维护

16套范例位于dist/depth-examples/Pxx.html；index.html是用相同渲染器绘制的六层节点对照，不另写示意外形。图库提供完整多层范例入口。所有默认模板代码和数量保持不变。

src/hierarchy.cjs负责深度度量与风格角色；engine.cjs用于测量，render.cjs用于表现；media.cjs直接复用完整场景。打包/安装时随运行资源一起校验；Skill依然只需提交Markdown和模板名。

## 参考与边界

- [MindNode Themes](https://www.mindnode.com/support/guides/themes)支持按不同节点层级提取样式，说明层级主题可以保留不同层级的表现。
- [Xmind Style](https://xmind.com/user-guide/style-new)将主题外形、文字与分支外观分别处理。

以上资料支持层级样式和分支样式分离的方向；本文的角色、递推公式和下限是本项目的设计，不声称是厂商内部算法或用户使用率结论。
