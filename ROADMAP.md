# Roadmap / 路线图

## Phase one: Skill-first / 一期：让 Skill 好装、好用、可维护

Version 1.0.0 packages the shared Mindbox renderer and 16 complete styles for distribution as an Agent Skill. The project and packaged Skill use the same release version.

- Complete installed package: instructions, scripts, templates, fonts and licenses.
- Unified Skills CLI installation for Codex, Claude Code, Cursor, OpenClaw and CodeBuddy, plus a WorkBuddy shared-directory adapter and Doubao Work shared discovery.
- Editable mindmap Markdown → standalone interactive HTML.
- Natural-name and fixed-code style selection; selected style plus editable Markdown in the reader.
- Adaptive deeper hierarchy, folding, direct node editing, reading guidance and PNG/WebP export.
- Same-topic HTML continuation, source-note preservation, explicit updates and rollback.
- Bilingual onboarding, sixteen task examples, automated checks and release assets.

Near-term iteration will focus on observed install failures, layout readability, browser export compatibility and improvements to the existing 16 styles. Task-based recommendations will be revised from actual feedback; no invented popularity scores.

## Phase two: integrations / 二期：Agent、MCP 等对接

Planned exploration, **not shipped capabilities**:

- Dedicated Agent workflows for organizing, reviewing and iterating on a map.
- An MCP adapter over the shared content/render contract.
- Other tool and knowledge-workflow integrations selected from concrete user needs.

No delivery dates, API stability or host coverage are promised yet. Proposals should explain the real workflow and why a Skill alone does not solve it.
