管理 Skill：查看、更新与卸载

以下命令管理全局安装的 Mindbox；项目安装请看完整命令说明 ↗。

查看已安装

npx skills list -g

列出全局 Skill，确认 Mindbox 的安装位置与助手。

更新／升级 Mindbox

npx skills update mindbox -g

更新与升级是同一个操作，仅指定 Mindbox，不会批量升级其他 Skill。更新后开启新助手会话；固定版本的安装继续跟随原版本，切换版本请看版本说明 ↗。

卸载 Mindbox

npx skills remove mindbox -g

确认后移除各助手中的 Mindbox。已生成的 HTML 不受影响；重新安装使用上方安装命令。WorkBuddy 额外链接的清理见适配说明 ↗。

只读检查新版本、固定版本与旧安装器回退，见版本管理 ↗。

安装需要 Node.js 22.20+ · 查看 HTML 无需安装
  1. 装一次运行安装命令，按提示选择你正在使用的助手。安装后开启新会话，跨项目复用。

一本很短的说明书改文字、选样式、安装 Skill
01 / 改文字

直接在图上改。

单击选中，双击改字；节点旁的 − 收起分支，+ 数字展开。选中后按 Tab 增加子节点，Enter 增加同级，Delete 删除。操作后保存 HTML。

用 $mindbox 将【我的主题或资料】整理成可编辑的思维导图。
例如：用彩虹经典梳理一次产品评审。
同一话题继续更新这份 HTML。
02 / 选样式

说清用途，我们来推荐。

16套完整样式分别服务阅读、工作、写作和构思，不需要自己搭配组件。

阅读
文章用极简，长文用知识提纲，复习用语义索引。
工作
汇报用商务蓝图，项目用项目分解，职责用组织分层。
表达
草稿用随手画画，演示用彩虹经典，讲解用概念分组。
构思
脑洞用脑洞涂鸦，收集用便签共创，讨论用彩色研讨。

告诉Agent你要完成的事情，它会先选好整套样式；也可以直接说喜欢的样式名称。

03 / 给 Agent

一句话，也能指定样式。

“把这篇文章画成思维导图，用极简。”

“用脑洞涂鸦整理我的产品想法。”

“保留内容，换成商务一点的风格。”

来源位置、页码或代码路径会随导图内容保留。图里的层级表达以原资料为依据。

本站体验不上传资料；在 Agent 中处理资料时，沿用该工具的模型与数据设置。

离线 HTML 不会自动覆盖磁盘文件；请点击“保存 HTML”保留修改。交给 AI 续改时，提供这份最新文件。Mindbox 适合层级整理；精确时序、跨节点关系和协同编辑不在当前范围。
