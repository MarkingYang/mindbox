YOUR FIRST MAP / 第一次使用

一段笔记，
一张可以接着改的图。

把 Mindbox 装进现有 AI 助手。从生成第一张脑图，到保存、分享，跟着做一次。

01 / INSTALL

选择你的助手，安装一次。

需要 Node.js 22.20+，以及能运行本地 Skill 的 Codex、Claude Code、Cursor 等助手。在终端运行，按提示选择助手：

npx skills add MarkingYang/mindbox -g

此命令安装公开仓库的当前版本。安装后开启新的助手会话。WorkBuddy、豆包工作或固定稳定版，请看兼容与安装说明。

02 / ASK

不用准备长文档，先试这一段。

用 Mindbox 整理下面的周末计划，选一套适合生活规划的样式，生成可编辑、可离线打开的 HTML：

这个周末想做三件事。读书：读完第二章，记下三个问题。运动：周六走路半小时，下雨就在家拉伸。下周准备：列出周一最重要的三件事，提前整理要用的资料。

把这段发给助手，也可以换成自己的笔记。明确说“用 Mindbox”；Codex 中也可以使用 $mindbox。

03 / EDIT

打开 HTML，直接改。

  • 点节点旁的按钮，折叠或展开分支。
  • 双击改字；选中节点后，Tab 加子节点，Enter 加同级。
  • 点击“保存 HTML”，下载包含最新修改的文件。

想先看成品？打开一份真实示例 →

04 / CONTINUE

再说一句，继续想。

保留内容，换成「浮生小趣」。

在“下周准备”下面补上“周日晚上检查日历”，其他分支保持不变。

如果在浏览器里改过，先保存，再把最新 HTML交给 AI。生成时附带的 Markdown 是快照，不会跟着浏览器修改自动同步。

05 / SHARE

发出这一个文件就够了。

对方用浏览器就能打开，无需安装 Mindbox。也可以在脑图中按需导出 PNG 或 WebP；WebP 编码取决于浏览器支持。

Mindbox 整理笔记、计划和想法的层级。资料读取、模型和权限由你的 AI 助手提供。HTML 不会自动覆盖磁盘原文件，请保存修改。

06 / MANAGE

安装之后，也用同一套命令。

查看全局安装：

npx skills list -g

更新／升级 Mindbox：

npx skills update mindbox -g

卸载 Mindbox：

npx skills remove mindbox -g

更新后开启新助手会话；卸载保留已生成的 HTML。重装使用上方安装命令。项目范围、只读检查版本、固定版本和 WorkBuddy 额外链接清理，见完整命令说明。
