# 周末项目别烂尾：先交一个能用的版本

适合：独立开发者与项目负责人。
把大愿望切成一条能体验、能验证、能收尾的路径。

```mermaid
mindmap
  root((周末项目别烂尾：先交一个能用的版本))
    先缩到一个真实问题
      为一个具体的人做
        他现在怎么凑合解决
        最想省掉哪一步
      写一句交付承诺
        做完能体验到什么
        这次明确不包含什么
    切出一条完整路径
      从输入走到结果
        先让主路径接起来
          例：给收藏夹做一个寻宝入口
            输入三条自己常用的链接
            按想找的东西生成入口卡片
              点开后仍能回到原网页
        再补必要的错误提示
      给每一段一个验收点
        有东西可以点或看
        用用户行为而非完成百分比
    先交给一个人试
      观察真实使用
        不先替用户解释每一步
        记下卡点与误解
      按影响收敛修改
        挡住主路径的先修
        装饰和扩展排到后面
    给这一轮一个结尾
      留下能继续的交付
        说明如何打开与保存
        记录已知边界
      决定下一步而非无限加需求
        继续解决哪个问题
        也可以选择就此停下
```

这是Mindbox编辑的实践范例，不是效果承诺；时间安排与检查项可按实际情况修改。
