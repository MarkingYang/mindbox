# 看完长文，只留下这5件事

适合：忙碌的读者。
从满屏信息中，留下主张、依据、边界、联系与下一步。

```mermaid
mindmap
  root((看完长文，只留下这5件事))
    作者到底在说什么
      压成一句话
        谁遇到什么问题
        作者建议怎么做
      删掉热闹的修饰
        标题不等于结论
        先找可被反驳的主张
    凭什么相信它
      区分证据和故事
        找原始出处
        看样本和时间
      保留不确定性
        例子不代表普遍规律
        数据缺失就记为待查
    什么情况下不成立
      找适用前提
        面对哪类人
        需要什么资源
      写下一个反例
        条件换了还成立吗
        有没有相反解释
    与我知道的怎么连
      找一个旧经验
        相同之处是什么
        哪里修正了旧认识
      用自己的话解释
        不抄原句也能说清吗
        还卡在哪里
    我接下来做什么
      只挑一个小动作
        今天能试哪一步
        用什么现象判断有用
      留一张回看卡
        一句收获
        一个未解的问题
```

这是Mindbox编辑的实践范例，不是效果承诺；时间安排与检查项可按实际情况修改。
