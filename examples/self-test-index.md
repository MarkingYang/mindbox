# 复习索引：从看过到答得出

适合：学生与知识整理者。
把知识点变成可回答的问题，找到还不清楚的连接。

```mermaid
mindmap
  root((复习索引：从看过到答得出))
    先问它是什么
      一句话解释概念
        不用原句能否说明白
        说出关键条件
      给一个自己的例子
        它为什么属于这个概念
        哪些细节不可缺少
    再问它不是什么
      比较容易混淆的词
        相同的部分是什么
        差别落在哪个条件
      找一个反例
        看起来像却不成立
        写清为什么不能套用
    然后试着用一次
      把答案藏起来再做
        先写自己的判断
        再对照材料找差异
      换一种情境追问
        条件改变会怎样
        能否解释自己的步骤
    把错题连回知识网
      分清卡在哪里
        记不住定义还是不会使用
        漏了前提还是证据不足
      给下次留一个入口
        一句纠正后的解释
        一个还想自测的问题
```

这是Mindbox编辑的实践范例，不是效果承诺；时间安排与检查项可按实际情况修改。
