# 第一稿难写？先把线团摊开

适合：写作者与表达练习者。
先摆出材料和矛盾，再决定这篇文字的骨架。

```mermaid
mindmap
  root((第一稿难写？先把线团摊开))
    先找到一个人
      这段话写给谁
        他已经知道什么
        现在最想弄明白什么
      确定一次阅读的收获
        能回答哪个问题
        不要一篇包办一切
    把素材倒在桌上
      事实和感受分开放
        哪件事真的发生过
        哪句话只是我的推测
      留下鲜活细节
        一个场景或对话
        一个改变方向的瞬间
    找到值得讲的张力
      前后有什么变化
        原来以为是什么
        后来为什么改了想法
      只保留一条主线
        哪段推动了问题
        哪段可以另写一篇
    让第一稿先走完
      先写最想写的一段
        开头可以之后再写
        卡住的地方留一句问题
      第二遍再打磨
        删掉重复与空话
        把抽象判断落到例子
```

这是Mindbox编辑的实践范例，不是效果承诺；时间安排与检查项可按实际情况修改。
