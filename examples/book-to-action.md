# 读完就忘？把一本书变成一次行动

适合：读书者与终身学习者。
不急着摘抄整本书，先带走一个值得验证的改变。

```mermaid
mindmap
  root((读完就忘？把一本书变成一次行动))
    带着问题翻开书
      我为什么读它
        最近哪个难题反复出现
        想改变哪一个做法
      给阅读划边界
        先读最相关的一章
        不强迫每页都做笔记
    让观点长出自己的话
      合上书复述
        这一章想解决什么
        凭什么这样解释
      留下概念的边界
        它与相近概念有何不同
        哪个例子会不适用
    把书放回真实生活
      找一次亲身经历
        过去我怎么做
        这次能换哪一步
      邀请一个反对意见
        最可能失败在哪里
        还缺什么证据
    做一个小小验证
      试一次就够具体
        何时何地开始
        最低做到什么算完成
      回看而非自责
        发生了什么变化
        保留改法或换一个试验
```

这是Mindbox编辑的实践范例，不是效果承诺；时间安排与检查项可按实际情况修改。
