# 读AI报告，先问这6个问题

适合：研究者与长文精读者。
把好看的结论拆回研究问题、口径、证据和边界。

```mermaid
mindmap
  root((读AI报告，先问这6个问题))
    它真正研究什么
      把问题写窄
        讨论能力还是实际使用
        解释现状还是预测未来
    谁被算进了样本
      找数据来源
        受访者怎么被选中
        谁没有被观察到
    指标到底怎么算
      确认分子与分母
        按人、请求还是任务计数
          例：问卷写使用或计划使用
            不要改写成已经每天使用
            回看相应问题的受访人数
        比例和绝对量不要混用
    与什么做了比较
      核对比较条件
        时间和任务是否一致
        基线有没有被改变
    结论到哪里为止
      保留作者的限制
        相关关系不等于因果
        平台样本不等于全体人群
    我能怎么使用它
      把研究接回自己的问题
        哪些判断需要本地验证
        哪些信息暂时无法回答
```

这是Mindbox编辑的实践范例，不是效果承诺；时间安排与检查项可按实际情况修改。
