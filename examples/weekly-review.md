# 周报别写流水账，讲清3个判断

适合：产品运营与业务负责人。
把忙了什么，换成发生了什么、为什么、下一步怎么办。

```mermaid
mindmap
  root((周报别写流水账，讲清3个判断))
    发生了什么变化
      先给一个核心结论
        本周最重要的变化
        它对目标意味着什么
      把证据放到旁边
        数值要带时间窗口
        用同口径基线比较
      说明观察的边界
        样本是否足够
        缺失数据不要补成事实
    为什么值得关注
      区分相关与原因
        同时发生不等于因果
        列一个替代解释
      找到可以验证的假设
        哪一步最可能有阻力
        还需要看什么反馈
      讲清影响范围
        影响哪些用户
        现在处理的必要性
    下一步怎么做
      只保留优先动作
        负责人和下一次交付
        什么情况下改变计划
      明确需要的协助
        需要谁做什么决定
        最晚什么时候确认
      约定回看的信号
        用哪个结果判断进展
        什么时候复盘取舍
```

这是Mindbox编辑的实践范例，不是效果承诺；时间安排与检查项可按实际情况修改。
