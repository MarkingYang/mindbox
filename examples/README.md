# Examples / 16个值得展开的问题

每套样式恰好一份完整原创范例。目录与目标读者以[catalogue.json](catalogue.json)为准，全文在对应Markdown中；生成的HTML使用统一的所选样式/Markdown编辑器。公开网页提供HTML与图像，不提供中间Markdown下载。

运行`npm run build`后，打开`dist/showcase/index.html`查看16份完整范例；首页每张样式卡也预览并打开相应内容。封面只取正文的有限分支，完整文件保留所有节点和更深的案例。

选题覆盖阅读学习、工作规划、写作表达、灵感构思。[选题依据](../docs/research/showcase-topics.md)记录原始来源与样本人群；它们支持需求方向，不证明这些标题的流量或效果。方法、议程与小故事是原创编辑建议，可按实际场景继续修改。

`doodle-story.md`是首页短动图的13节点故事，完整P67内容在`creative-ideas.md`。动图从共用阅读器导出；assets/showcase/中的元数据记录来源和矢量场景指纹。修改渲染或故事后需重新导出并核对，不能只更新静态海报。

`knowledge-work.md`保留通用文字编辑与结构验证样例。`dist/depth-examples/index.html`继续比较16套样式的层级延展，兼容旧的study-notes.html地址。
