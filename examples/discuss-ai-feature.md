# 要不要加AI功能？把分歧放上同一张图

适合：研讨组织者与跨职能团队。
先对齐事实和未知，再比较方案与要验证的风险。

```mermaid
mindmap
  root((要不要加AI功能？把分歧放上同一张图))
    先放能核对的事实
      用户究竟卡在哪
        记录真实场景与原话
        把推测单独标出来
      成功需要什么证据
        任务是否更容易完成
        用户是否理解输出边界
    再放不同的方案
      先试最简单的路
        改流程能否解决
        普通搜索或规则是否足够
      AI方案按任务比较
        需要找资料还是采取行动
        多复杂的链路才有必要
    让顾虑也有位置
      输出可能错在哪里
        错误后果与复核方式
        失败时怎么退回原流程
      交付还需要什么
        可用材料与权限
        运行与维护的负担
    只做一个可验证的决定
      先缩小试点
        选一个场景与一组样本
        写清暂停和继续的条件
      记录分歧如何被回答
        谁负责补哪条证据
        什么时候再看一次结果
```

这是Mindbox编辑的实践范例，不是效果承诺；时间安排与检查项可按实际情况修改。
